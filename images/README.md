## Swapping in different shots

Your full photo set (22 photos) is still in `/Users/abdul/Desktop/Car Photos` if you'd rather use different angles — just export/compress a replacement as a JPEG and overwrite the matching filename above (keep the same name so the site doesn't need any code changes).

Tips:
- Keep each file under ~500KB so the site loads fast — export at "Large" or ~1200–1800px on the longest side, not the full original resolution.
- If a file goes missing, that section just shows a plain dark background instead of a broken image, so it's safe to swap files one at a time.
